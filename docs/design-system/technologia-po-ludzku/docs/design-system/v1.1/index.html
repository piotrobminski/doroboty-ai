Public and persona workspace navigation

Owner: Shell

  • Named Base UI public mobile modal with focus containment, Escape and trigger return.
  • Workspace mobile navigation is an expanded inline menu, with Escape return.
  • Role selection is a simulation.

HP02 / c03

Task and submitted-record headers

Owner: PageTitle / ApplicationRecord

  • One H1 with optional eyebrow, description and wrapping action.
  • Graphite header identifies the immutable submitted record.
  • Collage is restricted to discovery contexts.

HP03 / c20 · c25

Named groups within one form

Owner: FormSection / Field

  • Semantic section with a unique heading ID.
  • Field has an explicit label/control association; prefilled text is excluded from its name.
  • Groups are not a simulated stepper.
  • Preserve source, generated and approved text separately.

HP04 / c20 · c25

Submitted materials and CV

Owner: RecordSheet / CvAttachment / ApplicationRecord

  • Base UI owns actual tabs and keyboard behavior.
  • One surface contains snapshots, notes and actions.
  • Only the CV panel has file controls and a matching local preview.
  • Custom CV snapshots keep complete text.

HP05 / c19

Recorded event history

Owner: ProcessTimeline

  • Ordered actual events with machine-readable time.
  • Latest event has aria-current=step.
  • Candidate projection excludes employer notes.
  • Materials precede history on narrow screens.

HP06 / c22 · c24

Persistent feedback and recovery

Owner: Notice / Empty

  • Info, success and warning are separate tones with text.
  • Errors identify repair and focus the affected field.
  • Import/reset remain confirmed; failures preserve data.

Host extensions retain their meaning.

  • Scenario MatchScore: a fixed example, never a hiring probability. Bands 0–39 red #FF6B79, 40–59 orange #FFB15C, 60–79 yellow #FFE45B, 80–100 green #00C853; ink text. These colors are independent from C area tones.
  • SalaryFact: retain real record currency (PLN/EUR), basis (gross/net), period (month/year) and absence. No fabricated amounts or conversions.
  • OfflineMap: local grouped markers and complete matching links; no remote tiles, geocoding or inferred location.
