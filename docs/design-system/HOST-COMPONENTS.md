## Shared additions and compositions

- [DiscoveryHero](../../src/features/public/discovery-hero.tsx): one source-derived discovery anatomy for home/listing, with title, eyebrow, description and optional actions; exact approved local collage.
- [AreaIcon/AreaLabel](../../src/features/jobs/area-label.tsx): source C SVG symbols and equal-area tonal labels; CompanyLogo reuses AreaIcon for the small marker.
- [FormSection](../../src/components/form-section.tsx): indexed, named section inside one form; reused for profile/company/job editing. It is not an interactive stepper.
- [EmployerJobEditor](../../src/features/prototype/job-editor.tsx): user-approved three-step composer (Stanowisko → Umiejętności i pytania → Podgląd), with real validation, back navigation, recoverable scoped drafts and explicit publication. Preview/Publish actions confirm review/publication; there are no separate approval checkboxes. [CompetencyEditor](../../src/features/prototype/competency-editor.tsx) owns one selected skill's editing, selection and focus inside step two. This is a host extension of c08–c11/c20–c25 and HP02/HP03, using the existing fields/actions and violet current-state tokens. The source's generic three-stage anatomy is adapted to the approved contribution-question workflow; it does not change FormSection into a stepper. [Task and evidence](../tasks/pr02-guided-local-simulation.md).
- [PageTitle/Notice/Empty/Shell](../../src/features/prototype/shell.tsx): task headings, info/success/warning feedback, honest empty/recovery surfaces, desktop workspace and Base UI public mobile navigation.
- [JobFiltersForm](../../src/features/jobs/job-filters.tsx): existing controlled FormSelect for all four facets, one All value, native disclosure in the listing; no standalone mobile filter component.

The user accepted the [1.1 specification](PROPOSED-1.1.md). These reusable compositions are now documented in the frozen reference [HP01–HP06 profiles](technologia-po-ludzku/docs/design-system/v1.1/index.html#profiles).

The existing `Field` owner in workspace.tsx gives every control a unique ID, explicit label association and text-only accessible name. FormSelect forwards that association to its Base UI trigger. Prefilled textarea contents never become part of their field label.

[CompetencyInsightPanel](../../src/features/prototype/competency-insight-panel.tsx) is an employer-only support region within the existing RecordSheet Answer tab (c20/c25, HP04). It uses paper/violet hierarchy, wrapping neutral evidence-status text, native details for exact response quotations and follow-up prompts. It is derived from immutable competency snapshots and is separate from the unchanged scenario MatchScore. It supplies no stage action or prewritten decision reason. [Task and evidence](../tasks/pr02-evidence-insight-and-demo.md).
