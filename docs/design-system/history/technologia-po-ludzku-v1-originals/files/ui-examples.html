02 / TOŻSAMOŚĆ, WARUNKI, PORÓWNANIE

Karta, którą łatwo przeczytać.

Te same funkcje renderują karty w listingu i tutaj. Zakładki w galerii działają tylko w pamięci tej strony. Ostatnia karta sprawdza długi tytuł, nazwę firmy, pojedynczy tag i brak widełek.

Pokaż przykład importu i renderowania
import { jobCardMarkup } from './listing-components.mjs';

list.innerHTML = jobs.map(job => jobCardMarkup(job, {
  saved: savedIds.has(job.id),
  href: `job.html?id=${encodeURIComponent(job.id)}`
})).join('');
// Obsługę data-save i przechowywanie stanu dodaje strona.
