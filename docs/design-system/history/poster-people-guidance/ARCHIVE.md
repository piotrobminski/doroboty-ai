# Historical Poster People integration guidance

These files preserve the project guidance from before the November 13, 2026 switch to **Technologia po ludzku**. They are historical engineering evidence, not instructions for new UI. Relative links inside these snapshots describe their original location at docs/design-system/; use the current [project guide](../../README.md) and the retained [legacy kit](../../agent-kit/) when investigating that history.

The legacy kit remains in place because current React code still imports its font and illustration. Its continued presence does not make it an alternative approved visual direction. Do not remove those assets until their runtime consumers have been migrated and verified.
